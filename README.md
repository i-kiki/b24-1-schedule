# Подписной календарь ИБ24-1

## Запуск
1. Создай **публичный** репозиторий на GitHub (например `ib24-1-schedule`).
2. Залей туда содержимое этой папки (`build_ics.py` и `.github/workflows/update.yml`).
3. Вкладка **Actions** -> `update-calendar` -> **Run workflow**. Через минуту в репозитории появится `ib24-1.ics`.
4. Ссылка на подписку:
   `https://raw.githubusercontent.com/<ТВОЙ_НИК>/ib24-1-schedule/main/ib24-1.ics`
5. iPhone: Настройки -> Календарь -> Учётные записи -> Добавить -> Другое -> Подписной календарь.
   Mac: Календарь -> Файл -> Новая подписка календаря.

## Если что-то не работает
- Сначала запусти локально: `python build_ics.py --dump`. Скрипт сохранит сырой ответ в `raw.json`.
  Если названия полей отличаются от ожидаемых (`date`, `beginLesson`, `endLesson`, `discipline`,
  `kindOfWork`, `auditorium`, `building`, `lecturer`), поправь их в `build_event()`.
- Если Action падает с ошибкой сети или 403: возможно, РУЗ не пускает зарубежные IP (раннеры GitHub
  в США). Тогда запускай скрипт по крону у себя (Mac/сервер в РФ) и заливай `.ics` в репозиторий
  или на любой хостинг.
